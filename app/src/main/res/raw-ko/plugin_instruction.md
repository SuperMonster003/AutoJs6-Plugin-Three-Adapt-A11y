3-Adapt A11y는 AutoJs6용 선택형 호환 도우미입니다. 어떤 이벤트도 처리하지 않는 접근성 서비스를 켜서, 공개된 지원 프로필에 포함된 앱에서 AutoJs6가 더 많은 정상 접근성 노드를 가져올 수 있도록 돕습니다. 자동화 동작은 여전히 AutoJs6 접근성 서비스가 수행하며, 플러그인은 화면 내용을 읽지 않고 네트워크도 사용하지 않습니다.

### 시작하기

1. AutoJs6와 3-Adapt A11y를 설치하고 플러그인을 연 다음 "호환 서비스" 상태 카드를 탭해 "호환 서비스 관리자"를 엽니다.
2. 기본 "제어 정책"인 "AutoJs6 따르기"는 AutoJs6 접근성 서비스가 켜져 있을 때 호환 서비스도 켭니다. 필요 없을 때는 "사용 안 함"을 선택합니다.
3. root, WRITE_SECURE_SETTINGS, Shizuku가 모두 없으면 "설정"에서 "시스템 접근성 설정"을 탭하고 AutoJs6 서비스와 3-Adapt A11y를 직접 켭니다.
4. "현재 지원 앱"에 있는 대상 앱을 완전히 종료했다가 다시 열고, AutoJs6로 페이지 노드를 읽습니다.

### 주요 기능

- **호환 서비스 관리자**: "상태"에서 호환 서비스와 AutoJs6 서비스의 현재 상태를 확인하고, "제어 정책"에서 "AutoJs6 따르기", "사용", "사용 안 함" 중 하나를 고릅니다.
- **자동 제어**: root, WRITE_SECURE_SETTINGS 또는 Shizuku를 허용한 뒤 "자동 제어"에서 해당 옵션을 켜면 플러그인이 선택한 정책에 따라 서비스를 직접 켜거나 끄며, 사용 중인 접근성 서비스 목록만 변경합니다.
- **중지된 서비스 복구**: 시스템 설정에는 켜져 있는데 서비스가 실행되지 않으면 플러그인이 같은 방법으로 서비스를 껐다가 다시 켭니다. 그럴 수 없으면 홈에 "호환 서비스가 실행되지 않음"과 "시스템 설정" 버튼을 표시합니다.
- **지원 프로필**: 홈의 "현재 지원 앱"에 검증된 앱을 표시하며, 이번 릴리스에서는 WeChat뿐입니다. 프로필은 문서에 적힌 앱 버전과 페이지에만 적용되며 모든 환경을 보장하지 않습니다.
- **개인 정보 보호**: 서비스 콜백은 아무것도 하지 않고 모든 접근성 이벤트를 무시합니다. 플러그인은 이벤트 내용, 루트 노드, 스크린샷, 사용자 콘텐츠를 읽지 않고 데이터를 저장하거나 업로드하지 않으며 네트워크 권한도 없습니다.
- **모양과 정보**: "설정"에서 "언어", "다크 모드", "테마 색상", "런처 아이콘"을 바꾸고 "호환 메커니즘", "개인 정보 보호", "제한 사항", "릴리스 기록"을 볼 수 있습니다.

### 요구 사항

- Android 7.0 (API 24) 이상, AutoJs6 6.8.0 이상. 노드 읽기와 동작은 AutoJs6 접근성 서비스가 담당합니다.
- 이 플러그인의 접근성 서비스는 호환 식별자로만 켜지며, 지원 프로필에 있는 앱의 이벤트만 받고 처리하지 않습니다.
- root, WRITE_SECURE_SETTINGS, Shizuku는 선택 사항이며 서비스를 자동으로 켜고 끄는 데만 쓰입니다. WRITE_SECURE_SETTINGS는 ADB 또는 root 셸로 부여합니다.
- 고급 보호 모드 조회 권한은 Android 17의 "고급 보호"가 이 서비스를 제한하는지 확인하는 데 쓰이며, 결과는 "설정"에 표시됩니다.

### 자주 묻는 질문

**서비스를 켠 뒤에도 노드가 달라지지 않음**

먼저 AutoJs6 서비스와 3-Adapt A11y가 모두 켜져 있는지 확인한 다음 대상 앱을 완전히 종료했다가 다시 엽니다. 효과는 앱 버전, 페이지, 기기, 시스템에 따라 다르며 보장되지 않습니다. WebView, Canvas, 직접 그린 화면의 컨트롤은 여전히 가져오지 못할 수 있습니다.

**시스템 설정에서는 켜져 있지만 홈에 "호환 서비스가 실행되지 않음"이 표시됨**

프로세스가 종료된 뒤에는 Android가 서비스를 자동으로 되살리지 않습니다. root, WRITE_SECURE_SETTINGS 또는 Shizuku가 있으면 플러그인이 자동으로 복구하고, 없으면 "시스템 설정"을 탭해 3-Adapt A11y를 껐다가 다시 켭니다.

**서비스 클래스 이름이 Google 선택하여 말하기와 같음**

일부 앱은 사용 중인 서비스의 클래스 이름으로 정상 노드를 제공할지 정하므로, 플러그인은 그 클래스 이름을 공개된 호환 식별자로만 사용합니다. 이 플러그인은 Google 선택하여 말하기가 아니며 Google과 관련이 없고, Google의 애플리케이션 ID, 서명, 이름, 아이콘도 사용하지 않습니다.

지원 프로필, 호환 메커니즘, 검증 기록은 [프로젝트 페이지](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Adapt-A11y)에서 볼 수 있습니다.
