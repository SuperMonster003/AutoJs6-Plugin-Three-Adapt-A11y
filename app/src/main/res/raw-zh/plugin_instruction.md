3-Adapt A11y 是 AutoJs6 的可选兼容服务: 它启用一个不处理任何事件的无障碍服务, 帮助 AutoJs6 从已发布支持配置的应用中获取更多正常的无障碍节点. 自动化操作仍由 AutoJs6 自己的无障碍服务完成, 插件不读取屏幕内容, 也不联网.

### 开始使用

1. 安装 AutoJs6 与 3-Adapt A11y, 打开插件, 点按 "兼容服务" 状态卡片进入 "兼容服务管理器".
2. 默认的 "控制策略" 是 "跟随 AutoJs6", 会在 AutoJs6 无障碍服务开启时同时开启兼容服务; 不需要时可以选择 "禁用".
3. 没有 root, WRITE_SECURE_SETTINGS 或 Shizuku 时, 在 "设置" 中点按 "系统无障碍设置", 手动开启 AutoJs6 与 3-Adapt A11y 两个服务.
4. 完全退出并重新打开 "当前支持的应用" 中列出的目标应用, 再用 AutoJs6 读取页面节点.

### 主要功能

- **兼容服务管理器**: 在 "状态" 中查看兼容服务与 AutoJs6 服务的当前状态, 在 "控制策略" 中选择 "跟随 AutoJs6", "启用" 或 "禁用".
- **自动控制**: 授予 root, WRITE_SECURE_SETTINGS 或 Shizuku 后, 在 "自动控制" 中开启对应的选项, 插件就会按所选策略自行开启或关闭服务, 并且只修改已启用无障碍服务的列表.
- **服务失效修复**: 服务在系统设置中显示已开启却没有运行时, 插件会通过上述方式把它关闭再开启; 无法自动处理时首页显示 "兼容服务没有运行", 并提供 "系统设置" 按钮.
- **支持配置**: 首页 "当前支持的应用" 列出已验证的应用, 本版本只有微信; 配置只适用于记载的应用版本与页面, 不保证所有环境.
- **隐私**: 服务回调不做任何处理, 忽略全部无障碍事件; 插件不读取事件内容, 根节点, 截图或用户内容, 不保存, 不上传数据, 也没有网络权限.
- **外观与信息**: 在 "设置" 中可以调整 "语言", "夜间模式", "主题色" 与 "启动器图标", 并查看 "兼容机制", "隐私", "限制" 与 "发行历史".

### 运行要求

- Android 7.0 (API 24) 或更高版本, 以及 AutoJs6 6.8.0 或更高版本; AutoJs6 的无障碍服务负责读取节点与执行操作.
- 本插件的无障碍服务只作为兼容标识开启, 只接收支持配置中应用的事件, 并且不处理它们.
- root, WRITE_SECURE_SETTINGS 或 Shizuku 授权是可选的, 只用于自动开启或关闭服务; WRITE_SECURE_SETTINGS 需要通过 ADB 或 root shell 授予.
- 查询高级保护模式的权限用于检测 Android 17 的 "高级保护" 是否会限制本服务, 结果显示在 "设置" 中.

### 常见问题

**开启后节点没有变化的情形**

先确认 AutoJs6 与 3-Adapt A11y 的服务都已开启, 再完全退出并重新打开目标应用. 效果取决于目标应用的版本, 页面, 设备与系统, 不保证成功; WebView, Canvas 与自绘界面中的控件可能仍然无法获取.

**系统设置中已开启, 但首页显示 "兼容服务没有运行"**

服务进程被结束后系统不会自动恢复它. 授予过 root, WRITE_SECURE_SETTINGS 或 Shizuku 时插件会自动修复; 否则点按 "系统设置", 把 3-Adapt A11y 关闭再开启.

**服务类名与 Google 随选朗读相同的原因**

部分应用会根据已启用服务的类名决定是否提供正常节点, 插件只把该类名作为公开的兼容标识使用. 本插件不是 Google 随选朗读, 与 Google 无关, 也没有使用 Google 的应用 ID, 签名, 名称或图标.

支持配置, 兼容机制与验证记录见 [项目主页](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Adapt-A11y).
