# AutoJs6 アクセシビリティ互換

## 目的

これは任意の試験的コンパニオンです. 公開済みサポートプロファイルの対象アプリから AutoJs6 がより正常なアクセシビリティノードを取得するために役立つ場合があります. 自動化は引き続き AutoJs6 のアクセシビリティサービスが実行します.

## サービスの有効化

1. AutoJs6 とこのコンパニオンをインストールします.
2. Android のアクセシビリティ設定で AutoJs6 サービスと AutoJs6 アクセシビリティ互換サービスを手動で有効にします.
3. サポートリストの対象アプリを完全に終了して開き直し, 同じ静止ページを複数回確認します.
4. 互換機能が不要なときはシステム設定でこのサービスを無効にします.

Android では通常のアプリがアクセシビリティサービスを無断で有効にできません. このコンパニオンはその制限を回避しません.

## 試験的な互換メカニズム

影響を受ける一部のアプリは, 有効なサービスの実装クラス名に基づいて通常のノードを公開するか判断する場合があります. このコンパニオンには現在のサポートプロファイルで必要な, 試験的に検証された次の互換クラス名が含まれます.

`com.google.android.accessibility.selecttospeak.SelectToSpeakService`

このコンパニオンは Google Select to Speak ではなく, Google との提携もありません. Google のアプリケーション ID, 署名, 名前, アイコンをコピーしません. このクラス名は公開済みの互換識別子としてのみ使用され, 対象アプリの更新後に動作しなくなる場合があります.

## 現在のサポートプロファイル

- WeChat (`com.tencent.mm`) はこのリリースで検証済みの唯一のプロファイルです.
- プロファイルは文書化されたアプリバージョンとページにのみ適用されます. 掲載はすべての環境での動作を保証しません.

## プライバシー

- サービスのコールバックは何も実行せず, すべてのアクセシビリティイベントを無視します.
- コンパニオンはイベントのソースやテキスト, ルートノード, スクリーンショット, ユーザーコンテンツを読み取りません.
- コンパニオンはデータを保存, 共有, アップロードせず, ネットワークにも接続しません.
- サービスは公開済みサポートプロファイルに記載されたパッケージ ID からのイベントのみを受信します.

AutoJs6 は引き続き独自のアクセシビリティサービスでノードを読み取り操作します. このコンパニオンはノードツリーを中継せず, 自動化操作も実行しません.

## 制限とリスク

互換性は対象アプリのバージョンとページ, 端末, システム実装に依存します. 成功は保証されません. このコンパニオンはページが公開していないセマンティックノードを作成できません. WebView, Canvas, カスタム描画画面のコントロールは引き続き利用できない場合があります.

対象アプリが検出方法を変更すると, このコンパニオンは機能しなくなる可能性があります. 自動化には対象プラットフォームの規則やアカウントリスク管理が適用される場合もあります. 自分の端末とアカウントでリスクを評価してください.
