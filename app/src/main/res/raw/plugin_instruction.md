# AutoJs6 微信无障碍兼容插件

## 用途

这是一个可选的实验性伴生插件. 它可能帮助 AutoJs6 在受影响的微信版本中获取较正常的无障碍节点. 自动化仍由 AutoJs6 自己的无障碍服务完成.

## 启用方式

1. 安装 AutoJs6 和本插件.
2. 在 Android 系统无障碍设置中手动启用 AutoJs6 服务和 AutoJs6 微信无障碍兼容服务.
3. 完全退出并重新打开微信, 然后在同一个静止页面连续检查多次节点结果.
4. 不需要兼容功能时, 在系统设置中关闭本服务.

Android 不允许普通应用静默启用无障碍服务. 本插件不会尝试绕过这个限制.

## 实验性兼容机制

部分微信版本可能根据已启用服务的实现类名决定是否公开正常节点. 本插件包含以下公开验证过的实验性兼容类名.

`com.google.android.accessibility.selecttospeak.SelectToSpeakService`

本插件不是 Google 随选朗读服务, 不隶属于 Google, 也不复制 Google 的应用包名, 签名, 名称或图标. 该类名仅作为明确披露的兼容标识使用, 并可能随微信更新失效.

## 隐私

- 服务回调为空操作并忽略所有无障碍事件.
- 插件不读取事件来源, 事件文本, 根节点, 屏幕截图或用户内容.
- 插件不保存, 分享或上传数据, 也不访问网络.
- 服务仅配置给微信包名 `com.tencent.mm`.

AutoJs6 会继续通过自己的无障碍服务读取和操作节点. 本插件不代理节点树或执行自动化动作.

## 限制和风险

兼容效果取决于微信版本, 设备和系统实现, 不提供成功保证. 本插件不能补全页面原本未公开的语义节点. 小程序, XWeb, Canvas 和自绘界面的控件仍可能不可用.

微信未来可能改变检测方式并使插件失效. 使用自动化也可能受到微信规则或账号风控限制. 请在自己的设备和账号上评估风险.
